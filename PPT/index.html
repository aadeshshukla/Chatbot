05 TOKENS & CONTEXT

What the model sees
on each turn.

A context window is the conversation material sent with one request. Our app estimates its size with characters.
WORDS·TOKENTOKENTOKEN

Tokens are model-sized text pieces.

Models read and generate text as tokens. A token may be a word, part of a word, punctuation, or whitespace. Token count is not the same as word count.

The visible stream arrives in text chunks. Each chunk is not guaranteed to equal exactly one model token.
